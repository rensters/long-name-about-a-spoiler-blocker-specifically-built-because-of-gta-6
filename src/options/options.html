How strong / weak / context work

Strong blurs on sight. Weak needs a second clue in the same post: a strong term, or a different weak or context term. Context words ("trailer", "ending", "leak") never blur alone and never pair with each other. They only count as that second clue.

Case, accents, leetspeak (GT4), dots and emoji between letters (G.T.A., GTA🔥6), hashtags, camelCase and 6 = VI = six are all handled for you. Start a line with // to make a group heading.
